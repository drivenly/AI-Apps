# AI Apps · Drivenly

Ferramentas pequenas e úteis que a [Drivenly](https://drivenly.io) cria com ajuda de IA e partilha de forma aberta. Cada pasta é uma ferramenta independente, com as próprias instruções.

| Ferramenta | O que faz | Onde roda |
|---|---|---|
| [Agrupar Seleção Elementor](<Agrupar Seleção Elementor/>) | Atalhos de teclado no editor do Elementor V4 que agrupam os elementos selecionados em um Div block ou Flexbox, como no Figma. | Plugin do WordPress |
| [Conversor de Imagens](<Conversor de Imagens/>) | Converte imagens em lote para WebP, JPEG, PNG ou AVIF, com controle de qualidade e de dimensões, sem enviar nada para a internet. | Navegador (um único arquivo HTML) |

## Encontrou um problema ou tem uma sugestão?

Abra uma [issue](https://github.com/drivenly/AI-Apps/issues) contando o que aconteceu, em qual ferramenta e, quando fizer sentido, quais versões você usa (navegador, WordPress, Elementor). São projetos mantidos no tempo livre da equipe, então as respostas podem demorar.

## English

Small, useful tools that [Drivenly](https://drivenly.io) builds with the help of AI and shares openly. Each folder is a standalone tool with its own instructions.

| Tool | What it does | Runs in |
|---|---|---|
| [Agrupar Seleção Elementor](<Agrupar Seleção Elementor/>) | Keyboard shortcuts for the Elementor V4 editor that wrap the selected elements in a Div block or Flexbox, like grouping in Figma. | WordPress plugin |
| [Conversor de Imagens](<Conversor de Imagens/>) | Batch-converts images to WebP, JPEG, PNG or AVIF with quality and size controls, without uploading anything. | Browser (a single HTML file) |

The tools' interfaces are in Portuguese. Found a bug or have an idea? Open an [issue](https://github.com/drivenly/AI-Apps/issues). Everything here is licensed under [GPL-2.0-or-later](LICENSE) and provided as is, without warranty.
